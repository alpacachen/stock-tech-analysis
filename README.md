# 股票技术分析工具

基于 TypeScript 的股票技术分析工具，支持获取股票历史数据并计算常用技术指标。

## 功能特性

- 通过股票中文名称自动查询股票代码
- 获取最近 100 个交易日的历史数据
- 计算并展示技术指标：
  - **MA** (移动平均线): MA5、MA10、MA20
  - **MACD**: DIF、DEA、BAR 及金叉/死叉信号
  - **KDJ**: K、D、J 值及超买超卖信号
- 美观的表格输出

## 快速开始

### 环境要求

- Node.js 18+

### 方式一：命令行运行

无需安装依赖，直接使用 npx 运行：

```bash
npx tsx analysis-stock.ts <股票中文名>
```

### 方式二：使用 OpenCode Agent（推荐）

本项目集成了专业的股票技术分析 Agent，可以提供更深入的技术分析报告。

**使用步骤：**

1. 在项目目录下启动 OpenCode：

```bash
opencode
```

2. 直接询问股票走势，例如：

```
请帮我分析一下沃尔核材的走势
```

3. OpenCode 会自动调用 `analysis-stock.ts` 获取股票数据，并基于技术指标（MA、MACD、KDJ 等）生成完整的技术分析报告，包括：
   - 趋势判断（短期/中期趋势）
   - 技术指标解读
   - 支撑阻力位分析
   - 操作建议
   - 风险提示

## 技术指标说明

### MA (移动平均线)
- MA5: 5日均线，反映短期趋势
- MA10: 10日均线，反映中期趋势
- MA20: 20日均线，反映中长期趋势

### MACD
- DIF: 快线
- DEA: 慢线
- BAR: MACD柱状图 = 2 × (DIF - DEA)
- 金叉: DIF 上穿 DEA，看多信号
- 死叉: DIF 下穿 DEA，看空信号

### KDJ
- RSV: 未成熟随机值
- K: 快速确认线
- D: 慢速主干线
- J: 方向敏感线 = 3K - 2D
- K < 20: 超卖区
- K > 80: 超买区
